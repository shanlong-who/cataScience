# Package index

## 启动培训应用

在本地 R 会话中打开经典版或扩展培训版。

- [`run_cata()`](https://shanlong-who.github.io/cataScience/zh/reference/run_cata.md)
  : 启动经典版“数据科学之旅”培训应用
- [`run_catas()`](https://shanlong-who.github.io/cataScience/zh/reference/run_catas.md)
  : 启动 cataScience 扩展培训版

## 检查和整理数据

- [`cata_read()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_read.md)
  : 读取培训数据文件
- [`cata_profile()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_profile.md)
  : 汇总数据表的结构与质量
- [`cata_missing()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_missing.md)
  : 统计缺失值和缺失模式
- [`cata_check_keys()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_check_keys.md)
  : 检查候选记录键
- [`cata_flag_outliers()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_flag_outliers.md)
  : 标记待检查值，不改变原始数据
- [`cata_join()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_join.md)
  : 关联数据表并返回审计记录

## 示例、分母与统计分析

- [`cata_example()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_example.md)
  : 加载有文档说明的示例数据
- [`cata_proportion()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_proportion.md)
  : 使用明确分母计算比例
- [`cata_count_status()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_count_status.md)
  : 汇总报告的二元状态，并保留未知情况
- [`cata_lao_analysis()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_lao_analysis.md)
  : 复现老挝培训的合成数据分析
- [`cata_mice_demo()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_mice_demo.md)
  : 用合成猫咪数据学习多重插补

## 可视化与结果沟通

- [`cata_plot()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_plot.md)
  : 使用明确变量名创建图表
- [`theme_cata()`](https://shanlong-who.github.io/cataScience/zh/reference/theme_cata.md)
  : 用于培训图表的清晰主题
- [`cata_report()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_report.md)
  : 生成独立的报告或 dashboard
- [`cata_export()`](https://shanlong-who.github.io/cataScience/zh/reference/cata_export.md)
  : 导出可复现的结果沟通项目
