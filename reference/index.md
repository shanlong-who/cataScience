# Package index

## Launch the training app

Open the bundled training app in a local R session.

- [`run_cata()`](https://shanlong-who.github.io/cataScience/reference/run_cata.md)
  : Launch the "A Journey of Data Science" training app
- [`run_catas()`](https://shanlong-who.github.io/cataScience/reference/run_catas.md)
  : Launch the extended cataScience workshop

## Review and prepare data

- [`cata_read()`](https://shanlong-who.github.io/cataScience/reference/cata_read.md)
  : Read a training dataset
- [`cata_profile()`](https://shanlong-who.github.io/cataScience/reference/cata_profile.md)
  : Summarise the structure and quality of a table
- [`cata_missing()`](https://shanlong-who.github.io/cataScience/reference/cata_missing.md)
  : Count missing values and patterns
- [`cata_check_keys()`](https://shanlong-who.github.io/cataScience/reference/cata_check_keys.md)
  : Check a proposed record key
- [`cata_flag_outliers()`](https://shanlong-who.github.io/cataScience/reference/cata_flag_outliers.md)
  : Flag values for review without changing them
- [`cata_join()`](https://shanlong-who.github.io/cataScience/reference/cata_join.md)
  : Join tables and return an audit

## Examples and denominators

- [`cata_example()`](https://shanlong-who.github.io/cataScience/reference/cata_example.md)
  : Load a documented example
- [`cata_proportion()`](https://shanlong-who.github.io/cataScience/reference/cata_proportion.md)
  : Calculate proportions with explicit denominators
- [`cata_count_status()`](https://shanlong-who.github.io/cataScience/reference/cata_count_status.md)
  : Summarise a reported binary status with unknowns kept visible
- [`cata_lao_analysis()`](https://shanlong-who.github.io/cataScience/reference/cata_lao_analysis.md)
  : Reproduce the synthetic Lao workshop analysis
- [`cata_mice_demo()`](https://shanlong-who.github.io/cataScience/reference/cata_mice_demo.md)
  : Explore multiple imputation using synthetic cats

## Visualise and communicate

- [`cata_plot()`](https://shanlong-who.github.io/cataScience/reference/cata_plot.md)
  : Create a chart with explicit variable names
- [`theme_cata()`](https://shanlong-who.github.io/cataScience/reference/theme_cata.md)
  : A clear theme for training figures
- [`cata_report()`](https://shanlong-who.github.io/cataScience/reference/cata_report.md)
  : Write a self-contained report or dashboard
- [`cata_export()`](https://shanlong-who.github.io/cataScience/reference/cata_export.md)
  : Export a reproducible communication project
